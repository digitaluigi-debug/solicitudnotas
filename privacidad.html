Política de privacidad de SOLICITUDNOTAS

Última actualización: 29 de septiembre de 2026

1. Información general

SOLICITUDNOTAS es una extensión de Firefox diseñada para automatizar la consulta y procesamiento de información necesaria para solicitudes de notas de entrega.

2. Información que procesa

Cuando el usuario inicia una búsqueda, SOLICITUDNOTAS puede procesar:

  • Números de factura introducidos o seleccionados por el usuario.
  • Información obtenida de las páginas del sistema SAP al que el usuario ya tiene acceso.
  • Archivos PDF de facturas necesarios para obtener el número de ENTREGA.
  • Información necesaria para obtener el número de VIAJE.
  • Información temporal necesaria para completar el proceso solicitado por el usuario.

3. Cómo se utiliza la información

La información se utiliza exclusivamente para realizar las funciones de SOLICITUDNOTAS: consultar la factura en SAP, obtener el número de VIAJE, procesar el PDF correspondiente y obtener el número de ENTREGA.

SOLICITUDNOTAS no utiliza esta información para publicidad, perfiles de usuarios, análisis de comportamiento ni fines comerciales.

4. Transmisión de información

La extensión se comunica con los sistemas web necesarios para realizar la función solicitada por el usuario. Las consultas se realizan como consecuencia de las acciones iniciadas por el usuario y utilizando la sesión y los permisos que el usuario ya tiene en dichos sistemas.

SOLICITUDNOTAS no transmite esta información a servicios de publicidad ni a terceros ajenos a los sistemas necesarios para realizar la función solicitada.

5. Almacenamiento

La extensión no mantiene una base de datos propia de las facturas procesadas. La información necesaria para una operación se procesa durante la ejecución de la función solicitada.

6. Datos personales

SOLICITUDNOTAS no tiene como finalidad recopilar nombres, correos electrónicos, contraseñas ni perfiles personales de los usuarios.

7. Seguridad

SOLICITUDNOTAS utiliza las conexiones disponibles del sistema web para realizar las consultas necesarias. La extensión no solicita al usuario que proporcione directamente sus contraseñas de SAP.

8. Cambios a esta política

Cualquier cambio importante en esta política se reflejará en una nueva versión de esta política.

9. Contacto

Para preguntas relacionadas con esta política de privacidad o con SOLICITUDNOTAS, puede utilizarse el correo de contacto indicado en la página del complemento.
